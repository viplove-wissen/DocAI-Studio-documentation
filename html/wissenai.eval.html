wissenai.eval.llm_eval module

Package that provides helper functions to evaluate LLM applications. It covers metrics from several frameworks such as RAGAS, Deepeval, Bert Score, BLEU and ROGUE score from evaluate module

wissenai.eval.llm_eval.eval_llm_summary_byembed(reference: str, candidate: str) → Dict[str, float][source]

Evaluate the quality of a candidate sentence (model-generated) against a reference sentence (human-provided) BERTScore, a metric that uses embeddings to assess semantic similarity.

BERTScore calculates precision, recall, and F1 score by comparing embeddings of the candidate and reference sentences. It is better than n-gram based metrics Args:

reference (str): The human-provided reference sentence (ground truth). candidate (str): The model-generated candidate sentence to be evaluated.

Returns:

Dict[str, float]: A dictionary containing the BERTScore values for Precision (0 to 1), Recall (0 to 1), and F1 (0 to 1) (Higher the better).

Example return value: {

“Precision”: 0.8234, “Recall”: 0.8123, “F1”: 0.8178

}

wissenai.eval.llm_eval.eval_llm_summary_byword(predictions: List[str], references: List[str]) → Tuple[Dict[str, float], Dict[str, float]][source]

Evaluation can be done on RAG outputs or LLM summarization outputs using the two scores BLEU and ROUGE. These metrics use an algorithm that finds a score which is the word by word difference between the reference (ground truth) and the LLM output. BLEU score: measures the similarity between the machine-translated text and the reference translations using n-grams ROUGE score measures the similarity between the machine-generated summary and the reference summaries using overlapping n-grams,word sequences that appear in both the machine-generated summary and the reference summaries Args:

predictions (List[str]): list of predicted sentences references (List[str]): list of lists of reference sentences (since each predicted sentence can have multiple references), reference sentences refer to ground truth

Returns: Tuple[Dict[str, float], Dict[str, float]]: Two dictionaries containing the BLEU (0 to 1) and ROUGE (0 to 1) scores, respectively (Higher th better). Example output format : {‘bleu’: 1.0, ‘precisions’: [1.0, 1.0, 1.0, 1.0], ‘brevity_penalty’: 1.0, ‘length_ratio’: 1.1666666666666667, ‘translation_length’: 7, ‘reference_length’: 6} {‘rouge1’: 1.0, ‘rouge2’: 1.0, ‘rougeL’: 1.0, ‘rougeLsum’: 1.0}

wissenai.eval.llm_eval.eval_rag_auto(query: str, answer: str, contexts: List[List[str]]) → Tuple[float, float][source]

Evaluate RAG application for two RAGAS metrics that DOES NOT require Ground Truth to be provided. These metrics are mathematical and use LLM to make computations by reprompting LLM for specific data. Faithfulness: This measures the factual consistency of the generated answer against the given context Answer Relevancy: focuses on assessing how pertinent the generated answer is to the given prompt

Args:

query (str): Query from user answer (str): Final output from the RAG pipeline from the LLM contexts (List[List[str]]): top N contexts retrieved from the vector database by retriever

Returns:
Tuple[float, float]: A tuple containing two float values:

  • The faithfulness score (float) (0 to 1) (Higher the better).

  • The answer relevancy score (float) (0 to 1) (Higher the better).

wissenai.eval.llm_eval.eval_rag_bulk(questions: List[str], answers: List[str], contexts: List[List[List[str]]], ground_truths: List[str]) → Dict[str, List[float]][source]

Evaluate RAG applications in bulk for two RAGAS metrics that require Ground Truth. These metrics are mathematical and use LLM to make computations by reprompting LLM for specific data. Includes all of the 4 RAGAS metrics defined in eval_rag_auto and eval_rag_groundtruth

Args:

questions (List[str]): List of queries from the user. answers (List[str]): List of final outputs from the RAG pipeline from the LLM. contexts (List[List[List[str]]]): List of top N contexts retrieved from the vector database by retriever, for each question. ground_truths (List[str]): List of actual ground truth answers for the given questions.

Returns:

Pandas Dataframe containing, questions, answers and corresponding eval scores (0 to 1) (Higher the better)

wissenai.eval.llm_eval.eval_rag_groundtruth(query: str, answer: str, contexts: List[List[str]], ground_truth: str) → Tuple[float, float][source]

Evaluate RAG applications for two RAGAS metrics that require Ground Truth to be provided. These metrics are mathematical and use LLM to make computations by reprompting LLM for specific data. Context Precision: metric that evaluates whether all of the ground-truth relevant items present in the contexts are ranked higher or not. Ideally all the relevant chunks must appear at the top ranks. Context recall: measures the extent to which the retrieved context aligns with the annotated answer, treated as the ground truth

Args:

query (str): Query from user answer (str): Final output from the RAG pipeline from the LLM contexts (List[List[str]]): top N contexts retrieved from the vector database by retriever ground_truth (str): Actual answer to the given question from user

Returns:
Tuple[float, float]: A tuple containing two float values:

  • The context_precision score (float) (0 to 1) (Higher the bettr).

  • The context_recall score (float) (0 to 1) (Higher the better).

wissenai.eval.llm_eval.eval_rag_risks_auto(query: str, answer: str, contexts: List[str]) → Tuple[float, float, float][source]

Evaluate RAG application or LLM outputs in general against 3 DeepEval metrics that Does NOT require ground truth to be provided. These metrics are mathematical and use LLM to make computations by reprompting LLM for specific data. Hallucination: A metric determines whether your LLM generates factually correct information by comparing the actual_output to the provided context Bias: A metric determines whether your LLM output contains gender, racial, or political bias Toxicity: A metric that evaluates toxicness in your LLM outputs such as Personal attacks, mockery, Hate, Dismissive statements Args:

query (str): Query from user answer (str): Final output from the RAG pipeline from the LLM contexts (List[str]): top N contexts retrieved from the vector database by retriever

Returns:

Tuple[float, float,float]: A tuple containing three float values: -Hallucination score (0 to 1) (Lower the better) -Bias score (0 to 1) (Lower the better) -Toxicity score (0 to 1) (Lower the better)
