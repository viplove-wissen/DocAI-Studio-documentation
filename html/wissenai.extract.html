wissenai.extract.knowledge_metadata module

wissenai.extract.knowledge_metadata.search_headers_in_json(json_data, query_text, search_method='fuzzy', label_filter=None, fuzzy_threshold=70, embedding_threshold=70)[source]

Search for headers in JSON data similar to the query text using the specified method, optionally filtering by label type.

Args:

json_data (list): List of JSON objects containing header and content information. query_text (str): The query text to match against headers. search_method (str): Search method (‘fuzzy’ or ‘embedding’). label_filter (str, optional): Filter headers by label_name (‘Section-header’,’Table-header’ or ‘Page-header’). If None, search all headers. fuzzy_threshold (int): Minimum fuzzy similarity score for a match (0-100). embedding_threshold (int): Minimum embedding similarity score for a match (0-100).

Returns:

str: Formatted string of matched headers, their content, and similarity scores.
