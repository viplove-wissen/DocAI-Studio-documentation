wissenai.extract.structured_chunking.structure.get_layout(path)[source]

Process a PDF file for structured data extraction and generate JSON output. This function orchestrates a pipeline to process a PDF file, including layout detection, table extraction, header mapping, and JSON output generation. It validates the input file, sets up directories, invokes specialized processing pipelines, and saves the results as JSON files. The function also generates image URLs for PDF pages and logs all activities.

Args:

path (str): Path to the input PDF file.

Returns:

  • dict: A dictionary containing: - status_code (int): HTTP status code (200 for success, otherwise error). - saved_json_path (str): Path to the final JSON output file. - message (str, optional): Error message if processing fails.

    • Raises:

    Exception: If any step in the processing pipeline fails, an error returned in the response.
