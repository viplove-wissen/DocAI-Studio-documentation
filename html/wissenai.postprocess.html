Bases: object

A class to extract and match fields and values from PDFs, generating citations with bounding boxes.

Supports both searchable and scanned PDFs using text extraction and OCR engines (Tesseract, PaddleOCR, EasyOCR). Matches fields and values using fuzzy matching and spatial analysis, and saves images of matched regions.
